# Smugglers / Bootleggers — concept approval v1

Status: **awaiting user approval**. Two-dimensional artwork only; no enemy modelling or rigging has begun.

Original designs for the five roles in GDD section 4.11. Every role has a full-body illustration and matching headshot, delivered as transparent PNGs without labels or text boxes.

Shared treatment: exaggerated painterly pulp-horror characters with worn period clothing, muted green/brown/charcoal colours and oxblood accents. These appearance choices are proposals, not approved GDD changes.

Generated using the built-in imagegen tool. `prompts.json` records the exact prompt set. Portraits develop the same character briefs as their corresponding full-body illustrations; minor costume detail variations remain subject to approval. PNG alpha is preserved unchanged; `validation.json` records the transparency checks.
